# Consultorio Dental Dra. Laura: Seguimiento de tratamientos

Proyecto desarrollado con Spec Driven Development (SDD) para reducir las
inasistencias y lograr que los pacientes terminen sus tratamientos de varias sesiones.

**URL en producción:** https://calm-pithivier-5e2786.netlify.app

## Estructura del proyecto
- `index.html`: aplicación web (lista de pacientes por recuperar, mensaje de WhatsApp, métricas).
- `docs/icp.md`: ICP y user persona (Dra. Laura y Marcela, la asistente).
- `docs/specs/spec-confirmacion-citas.md`: SPEC 1, confirmación automatizada de citas.
- `docs/specs/spec-seguimiento-tratamientos.md`: SPEC 2, seguimiento de tratamientos, con criterios de aceptación y métricas de éxito.
- `skills/brand-design.md`: sistema de diseño original.
- `.cursor/system-prompt.md`: contexto del agente.

## Despliegue
Publicado en Netlify como sitio estático.
