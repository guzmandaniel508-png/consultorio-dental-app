# Consultorio Dental Dra. Laura - Sistema de Gestión y Automatización

Proyecto desarrollado mediante **Spec Driven Development (SDD)** para reducir el ausentismo de pacientes y hacer seguimiento a tratamientos multisesión.

## Estructura del Proyecto
- `.cursor/system-prompt.md`: Contexto persistente e instrucciones generales del agente.
- `docs/specs/spec-confirmacion-citas.md`: Especificación técnica del feature principal.
- `skills/brand-design.md`: Sistema de diseño e identidad visual de la marca.
- `index.html`: Prototipo web funcional de la aplicación.
